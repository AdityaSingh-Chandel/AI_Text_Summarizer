# AI Text Summarizer

An AI-powered text summarization application built using Streamlit and Gemini API.

## Features

- Generate concise summaries
- Generate detailed summaries
- Generate bullet-point summaries
- User-friendly Streamlit interface

## Tech Stack

- Python
- Streamlit
- Gemini API
- python-dotenv

## Installation

```bash
pip install -r requirements.txt


# ****************************************************************************** #
How to Run

### 1. Clone the Repository

```cmd
git clone <repository-url>
```

### 2. Navigate to the Project Folder

```cmd
cd "<document-directory>\AI_Text_Summarizer"
```

Replace `<document-directory>` with the location where you cloned the repository.

### 3. Activate the Virtual Environment

**Windows CMD:**

```cmd
venv\Scripts\activate
```

### 4. Install Dependencies

```cmd
pip install -r requirements.txt
```

### 5. Run the Streamlit App

```cmd
python -m streamlit run app.py
```

The application will open in your browser.
